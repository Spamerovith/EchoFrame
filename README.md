# EchoFrame

**EchoFrame** is a free Geometry Dash mod for **Geode** featuring my own implementations of **Frame Extrapolation** and **AutoDeafen**, built from scratch specifically for EchoFrame.

Both features were developed specifically for EchoFrame and are **not taken from other mods**.

Press **Left Alt** to open the EchoFrame menu.

## Features

- **Custom-built Frame Extrapolation**
- **Custom-built AutoDeafen**
- Simple in-game menu
- Quick access with **Left Alt**
- Free to use

---

## Installation

1. Download the latest `echoframe.geode` file from the **Releases** section.
2. Make sure **Geode** is installed.
3. Place `echoframe.geode` into your Geode mods folder.
4. Launch **Geometry Dash**.
5. Press **Left Alt** to open the EchoFrame menu.

## Usage

Press **Left Alt** while Geometry Dash is running to open the EchoFrame menu.

From there, you can enable and configure the available features.

## Requirements

- **Geometry Dash**
- **Geode**
